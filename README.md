# Anim4u

## CelCraft Studio

[`celcraft-studio/`](celcraft-studio/) is a frame-by-frame 2D cel animation engine and agent skill:
a brush renderer running in headless Chromium, onion skinning, lip-sync, FFmpeg export, a CLI and an
MCP server. See [`celcraft-studio/README.md`](celcraft-studio/README.md) for setup and
[`celcraft-studio/SKILL.md`](celcraft-studio/SKILL.md) for the agent workflow.
